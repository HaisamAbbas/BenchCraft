F17 verification
================

Behavior
--------
- A first smoke records the application in the existing first-seen catalog if needed.
- Every smoke run writes the exact `ApplicationSpec` bytes to the verified artifact store and
  adds `application_artifact_id` to its manifest. Later specs with the same application ID
  do not replace the catalog record or conflict with it.
- Scoring reads the referenced frozen spec, and reports use it to expose the correct revision
  and app contract. Legacy runs without a frozen-spec reference keep their existing catalog
  fallback.
