# G22.5: image-first vision evaluator

The DeepEval plugin exposes `deepeval.vision_g_eval@1.0.0` as a worker-only, model-backed evaluator for single-turn image questions answered with text. The app-facing case input carries the image and prompt; the evaluator receives those fields, the reviewed reference answer, and the recorded application output. The worker projection prevents unrelated references, fixtures, metadata, and case extensions from being sent to the judge.

## Case and binding contract

```json
{"case_id":"receipt-01","input":{"prompt":"What is the total?","image":{"mime_type":"image/png","data_base64":"<base64 bytes>"}},"reference":{"answer":"$18.42"}}
```

`image` must contain exactly `mime_type` and `data_base64`. Supported MIME types are PNG, JPEG, and WebP. Encoded data is strictly base64-decoded, limited to 4 MiB, and checked against the matching file signature. URLs, file paths, extra image fields, unsupported types, malformed base64, mismatched signatures, and oversized images return not-applicable before any network call. The task comes from `input.prompt` or `input.question`. Prompt, reviewed reference answer, and recorded output are required non-empty strings of at most 20,000 characters.

The binding requires a rubric and an `openai_compatible` judge with a configured endpoint, model name, and key environment-variable name. The key is passed using the existing plugin `secret_env` map; it is never a metric parameter. HTTPS is required for non-loopback endpoints, redirects and ambient proxy variables are disabled, and response bodies are capped at 1 MiB. The endpoint's returned JSON must contain a finite 0-1 score and a non-empty reason of at most 2,000 characters. The harness's frozen decision rule decides pass/fail.

Image bytes, prompt, reference answer, and output leave the workspace for the configured judge endpoint. The metric is model-backed and must be explicitly allowed under evaluator policy. Calls are not retried internally. Reported token counts and one model call are recorded; provider cost is unknown unless reported, and the adapter does not invent a price. The raw artifact retains only the score explanation and model name, not image bytes or the provider response.

This slice supports text outputs only. It does not support audio, video, generated-image outputs, remote image fetching, DeepEval's upstream multimodal metrics, a visual review dashboard, or cross-provider score equivalence.
