# G01 — Consistent global configuration and scripting options

Status: IMPLEMENTED and independently reviewed.

The root CLI accepts `--config`, `--json`, `--non-interactive`, and `--policy` before a
command. An explicit config file replaces automatic project-config discovery and keeps the
existing config-file-relative path rules. Global policy is applied as a CLI override; a
command-local `--policy` wins when both are present. Global `--json` and
`--non-interactive` become defaults for nested commands that already expose those controls.
Non-interactive mode also prevents bare/chat TUI startup and refuses interactive setup, while
headless `chat --send` remains available.

Example:

```text
benchcraft --config ci/project.json --policy ci/policy.json --json --non-interactive run
```

Commands without a JSON output mode keep their documented output. Validation is recorded in
[G01 verification](../evidence/G01-verification.txt); the independent review found no
actionable findings in [G01 review](../evidence/G01-review.md).
