# F01 — Enforce rescoring budgets and quotas

Status: DELIVERED. Commit `1ac1a021dd436228aaf4a0e7eefe8dcd57b17aea` is pushed
and verified on `origin/fix/plugin-core-match`.

Stored-output scoring uses the engine's BudgetLedger, QuotaGate, retry classification
and backoff. Plan-based evaluation and session rescoring apply the chosen plan's bounds;
direct scoring inherits the original run's verified frozen plan. Each pass has a fresh
allowance, separate from original execution spend. Legacy smoke runs without a plan
retain unlimited defaults. Evaluations remain serial, respecting every concurrency cap.

Calls, reported tokens, projected cost and elapsed time are checked before dispatch.
Retries consume the same allowance. Quota waits and backoff count toward elapsed time;
cancellation interrupts quota waits. Evaluator preparation is lazy, so carried results
and missing evidence do not start a judge or consume calls. Time expiring during startup
prevents evaluation. Already running work retains its per-evaluation timeout.

The shared ledger now recognizes immutable token mappings stored in EvaluationResult;
previously their reported tokens were omitted. Unknown accounting remains explicit;
token ceilings cannot bound unreported use and cost ceilings remain soft estimates.

CLI/session output, pass events and stored reports expose budget accounting, quota
activity and stop reasons. No application runner is accessible from this service.
F06 (exit semantics) and F07 (planned missing-output denominators) remain separate work.

Validation: 96 initial affected tests passed; all 15 final budget tests passed,
including Unicode frozen plans and the audit's plan/policy evaluator-call ceiling.
All 38 additional existing report regressions passed. Two new report-output assertions
initially used incorrect command flags; their corrected forms passed in the final batch.
Full Mypy (140 files) and Ruff passed. Tests cover call/token/cost/wall limits,
unknown usage, carried results, missing evidence, retries, rate/backpressure quotas,
cancellation, persisted accounting and zero application invocations during rescoring.

Review found a Unicode hash mismatch in the new frozen-plan loader. Verification now
uses the frozen artifact's bytes hash, matching freeze_plan and the run service.
Final independent review: **No findings.** The reviewer also checked changed-artifact
rejection and legacy fallback. All final tests completed successfully after that review.
