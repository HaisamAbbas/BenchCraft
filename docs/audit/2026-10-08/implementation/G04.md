# G04 — Complete case-result export

Added `aibench export RUN_ID` for headless JSONL and CSV exports of every selected case and
repetition. Rows are built from committed run, work-item, execution-attempt, and scoring facts;
the export does not invoke applications, evaluators, or judges. It supports recorded scoring
pass selection, legacy runs without work graphs, work items without executions, and selected
metrics that have no result yet.

JSONL uses the versioned `aibench.case-result/1` row schema. CSV has a stable header and keeps
the full case, execution, and metric records in JSON cells, including timing, usage, tool
events, world state, trace references, observation completeness, and evidence references.
Direct formula-like CSV text is escaped for spreadsheet safety. `--no-content` withholds case
data, execution output/error/context/tool events/world state/usage, metric values/uncertainty/
resources, and free-text reasons while preserving identifiers and operational metadata. File
exports default to a deterministic workspace-local path; `--out -` is machine-output-only.

See [case-result-export.md](../../../case-result-export.md) and the export section in
[`support.md`](../../../support.md).
