# F02 — Preserve evaluator identity across carry-forward and caching

Status: VERIFIED. Independent review reported no remaining findings. This item is ready
to commit and push.

Carry-forward now requires the stored producer identity to match the current evaluator
identity before reusing a successful result. Identity covers plugin and package versions,
metric and rubric settings, judge configuration, instrumentation, worker dependency
versions, the worker Python runtime, and content visible through configured plugin import
paths. Worker-backed evaluators require known dependency and runtime identities regardless
of whether they call a model. Oversized, unreadable, or otherwise unidentifiable worker
environments continue scoring but do not reuse prior values.

The opt-in evaluation cache uses the same compatibility hash and is disabled when a
model-backed or worker-backed evaluator lacks a complete identity. A package, dependency,
runtime, or plugin source change therefore gets a fresh evaluation. Carried records identify
their source result, source scoring pass, and producer compatibility hash. Legacy carried
records resolve through their source-result chain; malformed or incomplete lineage fails
closed.

Configured plugin import paths are content-hashed incrementally with 10,000-entry and
64-MiB bounds. The interpreter probe records implementation, Python version, ABI cache tag,
platform, and machine. Installed distribution names and versions form the worker dependency
inventory.

Validation: the broader F02 regression batch passed 125 tests before the final interpreter
identity addition. The final carry-forward, registry, and cache suites then passed 41 tests,
including the interpreter probe and worker runtime-change cache-key regression. Ruff passed
for `src` and `tests`; Mypy passed for all 140 source files. One earlier run made while
multiple `uv` commands were starting reported a transient interpreter-probe failure; the
probe passed alone and in the final 41-test batch. See [verification](../evidence/F02-verification.txt)
and [independent review](../evidence/F02-review.md).
