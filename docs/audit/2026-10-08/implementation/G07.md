# G07 — Convenient bounded run controls

`aibench run` now accepts one-shot controls for selection (`--limit`, `--sample-size`, and
`--selection-seed`), repetitions, application/evaluator concurrency, attempts, evaluation
timeouts, call/token/time/cost budgets, cost estimates, and execution/evaluation caches.
Overrides are applied to a copy of the executable plan, then the complete plan is validated
and analyzed through the existing execution-policy gate before use. The resulting effective
plan is what the run freezes and hashes.

`--dry-run` emits a versioned `aibench.run-preview/1` document containing the effective plan,
plan/dataset/application/policy hashes, exact selected case IDs, metric binding hashes, and
execution/evaluation work counts. It exits before workspace creation, persistence, or dispatch.
The preview is JSON on stdout in both normal and `--json` modes; `--json` adds the shared CLI
envelope. Run IDs and run seeds are omitted because dry-run does not create them.

Plan selectors and predicates are preserved when a direct selector replaces the plan's limit
or sample. `--limit` and `--sample-size` cannot be combined; a seed requires a sample. The
full plan schema and policy ceilings remain authoritative, including finite-number validation
for wall-time and cost values. Advanced retry backoff, quotas, plugin settings, and release
gates remain plan-only controls.

Validation: 44 focused tests passed across run overrides, CLI run behavior, plan validation,
execution policy, and plan equivalence. Ruff passed for `src tests plugins`; Mypy passed for
149 source files; `git diff --check` passed. `python -m aibench run --help` listed the new
controls and dry-run switch.

Independent review found one actionable issue: an infinite wall-time budget could pass
validation and produce non-standard `Infinity` JSON. `BudgetLimits.max_wall_seconds` now
rejects non-finite values, with direct-override and CLI dry-run regressions. The reviewer
retested that case and reported no remaining findings; review evidence is in
[`G07-review.md`](../evidence/G07-review.md).
