# G22.3 measurement harness review

An independent defect-first review covered `scripts/measure_distributed_workers.py`,
`tests/test_distributed_measurement.py`, the three saved loopback measurements, and their audit
references.

The review first identified temporary-resource leaks if fixture setup failed, acceptance of
non-finite CLI numbers, and workloads with no practical wall-time bound. Those were addressed
with an outer cleanup scope, finite input checks and explicit input ceilings, and a measurement
deadline. A second pass identified the race where a worker could exit between inspection and
termination, plus ambiguity about whether the deadline covered shutdown. Cleanup now checks and
handles that process-exit race and continues through coordinator, server, and scratch cleanup;
the CLI help and evidence state that bounded teardown can add up to about 60 seconds beyond the
measurement deadline.

Final result: no remaining actionable findings. The test batch passed 18 tests (12 distributed-
worker regressions and 6 measurement-harness regressions). Ruff, formatting, Mypy for both changed
Python files, and `git diff --check` passed. The published measurements are Windows 11 / Python
3.12.10, one-host loopback results only; they do not establish external-network or cross-host
performance.
