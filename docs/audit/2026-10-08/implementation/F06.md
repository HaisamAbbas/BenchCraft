# F06 — Return honest scoring outcomes

Status: DELIVERED. The independent review finding on natural-language headless chat was
fixed and rechecked with no remaining findings.

Scoring passes now share one outcome calculation. Evaluator errors, cancelled work,
unavailable selected work, pending work, and a pass with no metric summaries are
incomplete and return exit 3. Legitimate not-applicable evidence and completed low scores
remain complete. For a complete pass, a failed declared release gate returns exit 1;
otherwise the pass returns 0. Gate results stay undecided when the scoring work is
incomplete.

The result is part of `ScoringReport`, the persisted `scoring_pass_completed` event, and
the stored report's scoring-pass accounting. `score --json` and `evaluate --json` include
the outcome, gate results, and matching exit code, and the process returns that code.
Text output states the outcome and code. Session `/rescore` returns the same fields, and
headless `chat --send /rescore --json` propagates incomplete scoring as exit 3 while a
quality-gate failure remains exit 1.

Validation: 84 focused tests passed across score/evaluate CLI, reports, selected work,
budgets, carry-forward, and scoring-service behavior. After the conversational chat fix,
48 outcome/chat/conversation tests passed, including the natural-language rescore path.
Ruff passed for `src` and `tests`; Mypy passed for all 140 source files. See the
[test and static-check record](../evidence/F06-verification.txt) and
