# F11 — Apply report redaction consistently

Status: DELIVERED. Every report format now receives the same recursively sanitized
document before rendering.

The JSON renderer previously serialized the report as-built while Markdown and HTML
sanitized strings during presentation. The renderer now applies the shared structured
sanitizer to string values and mapping keys before selecting JSON, Markdown, or HTML. When
different keys become identical after redaction, safe numeric suffixes keep both entries
and their values instead of making the output order-dependent.

Regression coverage checks per-case output and secret-shaped aggregate category keys across
all formats. It verifies colliding aggregate categories retain both numeric counts and that
selected/completed denominators are unchanged. The existing report regression expecting
exit 0 for a partial rescore was also corrected to the established F06 incomplete exit 3.

Validation and independent review are recorded in [verification](../evidence/F11-verification.txt)
and [review](../evidence/F11-review.md).
