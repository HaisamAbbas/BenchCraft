# F12 — Preserve numeric judge-repeat multiplicity

Status: DELIVERED. Numeric `expected_repeats` now reports every missing judge observation,
even though those repeats do not have scoring IDs.

The statistics helper previously placed anonymous missing repeats in a set of empty-string
IDs. The set collapsed multiple absences to one. Numeric expectations now build one missing
entry per absent repeat and attach a one-based `missing_repeat_ordinal`; `scoring_id` remains
`null` because no ID was provided. Explicit scoring-ID expectations continue to report each
absent ID by name. Unexpected units remain outside the expected-unit denominator.

Regressions cover zero, one, and multiple missing repeats in both numeric and explicit-ID
modes, including the audit's one observed versus five expected case. Validation and review
are recorded in [verification](../evidence/F12-verification.txt) and
[review](../evidence/F12-review.md).
