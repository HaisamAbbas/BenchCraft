# F16 — Keep plugin installer and optional environments current

Status: DELIVERED; independently reviewed and pushed as
`f513e256d9d39f1d0e158f947d0c0bd6ee5e210b`.

The project-managed plugin installer now upgrades its virtual environment's installer to
`pip>=26.2.1,<27` before installing adapter packages. The same floor is used in both optional
plugin CI jobs and documented manual setup. It covers the six distinct pip advisories seen
in the audit, whose highest fixed version is 26.2: [GHSA-4xh5-x5gv-qwph](https://github.com/advisories/GHSA-4xh5-x5gv-qwph),
[GHSA-6vgw-5pg2-w6jp](https://github.com/advisories/GHSA-6vgw-5pg2-w6jp),
[GHSA-58qw-9mgm-455v](https://github.com/advisories/GHSA-58qw-9mgm-455v),
[GHSA-jp4c-xjxw-mgf9](https://github.com/advisories/GHSA-jp4c-xjxw-mgf9),
[GHSA-wf93-45jw-7689](https://github.com/advisories/GHSA-wf93-45jw-7689), and
[GHSA-qwm4-qh6w-59xr](https://github.com/advisories/GHSA-qwm4-qh6w-59xr).

Ragas' declared dependency bounds now exclude the three fixable vulnerable releases:
`langchain-openai>=1.1.14,<1.2`, `langgraph-sdk>=0.4.6,<0.5`, and
`marshmallow>=3.26.2,<4`. Resolving the fixed `langchain-openai` version exposed that its
OpenAI SDK 2.26 requirement conflicted with the previous Instructor/OpenAI 1.x caps. Those
bounds now use the tested compatible line `instructor>=1.17,<1.18` and `openai>=2.26,<3`.
Tests exercise the real Ragas text metric and construct its built-in OpenAI judge without
making a network request.

CI audits the locked core/development requirements, the actual installed core/development
environment, and strict, exact-version snapshots of the installed DeepEval and Ragas
environments with pip-audit. Editable checkout packages are excluded from environment
snapshots; strict mode makes any other scan/collection gap fail.
Ragas 0.4.3's multimodal SSRF and DiskCache's unsafe-pickle advisories remain unpatched
upstream; the exact two exceptions, reachable-code analysis, and guard test are documented
in [the Ragas security note](../../../../plugins/ragas/SECURITY.md). The CI command ignores
only these two advisory IDs in the Ragas scan. The core dependency lock audit also runs in
strict mode, as do all environment snapshot audits.

Validation and final independent review are recorded in [verification](../evidence/F16-verification.txt)
and [review](../evidence/F16-review.md).
