# G22.14: Recorded provider-transcription accuracy

`deepeval.transcription_accuracy_g_eval` evaluates whether a voice agent's recorded
`provider_transcript` preserves the caller transcript stored on the same benchmark turn. It
uses the project's pinned DeepEval 4.2.5 `GEval` with a fixed speech-transcription rubric and
the configured judge. Each exchange receives a bounded scalar score; the episode score is the
mean of its exchange scores.

The evaluator requires `case.group_id` and `episode.turns`. It accepts a caller input string or
an object with a `transcript` field. Assistant output may be a string or the voice output object
with `transcript` and optional `provider_transcript`. Since the evaluator needs provider ASR
evidence, every turn in the stored episode must include a string `provider_transcript`. If any
turn lacks it, the full episode is not applicable; an empty string for a caller who spoke is
passed as the explicit `[NO WORDS RECOGNIZED]` marker for scoring. Malformed evidence also
returns not applicable without a judge request.

Evidence is capped at 50 turns, 16,000 characters for each caller or provider transcript, and
1 MiB of combined UTF-8 transcript text. The adapter does not send audio bytes to the judge,
decode audio, calculate word error rate, join separate caller segments into barge-in exchanges,
or perform live capture. The caller and provider transcript text does go to the configured
judge endpoint. Judge-dependent scores from different models are not directly comparable.
Provider usage from each exchange is retained; unknown token counts and cost stay unknown.

DeepEval's current beta documentation describes a dedicated `TranscriptionAccuracyMetric`, but
the repository pins 4.2.5 and the inspected pinned package does not export that class. This
implementation therefore uses the supported pinned `GEval` API without changing the dependency
pin or claiming parity with the upstream class. The adapter remains text-only; upstream
multimodal audio evaluation and acoustic diarization are separate unsupported capabilities.
