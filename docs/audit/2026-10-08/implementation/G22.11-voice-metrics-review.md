# G22.11 independent review

The independent reviewer found and the implementation resolved three issues:

- Conversation prefixes were previously copied and sent without a host-side limit. Prefixes now
  share bounded storage, and any history over 50 cases or 7 MiB of worker-JSON evidence becomes
  not-applicable before worker dispatch. Tests cover a 1,000-case group and pre-dispatch byte and
  turn limits.
- The accepted format could not represent user reprompts, yet the responsiveness description
  implied that it could; latency and interruption values were accepted although DeepEval ignored
  them. The metric contract now describes missing assistant audio as its sole represented
  responsiveness signal and rejects those unsupported fields. Regressions verify the actual
  alternating turn structure and missing-audio detector result.
- The host initially counted Unicode using a compact, unescaped representation rather than the
  worker's default JSON representation. It now matches the worker's Unicode escaping and
  separators exactly, with a CJK-heavy payload boundary regression.

The final read-only review found no remaining actionable findings. Verification passed: 14 voice
and episode tests, 4 DeepEval discovery tests, Ruff, formatting, Mypy on 175 core files and the
voice adapter, and `git diff --check`. No live provider call was made.
