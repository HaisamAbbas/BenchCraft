# F18 — Isolate terminal regression environments

Status: IMPLEMENTED and independently reviewed.

The advanced ConPTY harness now explicitly opts into `TERM=xterm-256color` and truecolor,
and removes inherited `NO_COLOR`. The RGB reply-rendering test does the same through
fixture-local environment changes. This keeps those assertions about the capable-terminal
contract instead of whichever flags happened to launch pytest.

Fallback contracts have separate coverage: a real ConPTY launched with `TERM=dumb` confirms
`/help` is processed by the plain prompt before checking that the composer hint is absent. A
Rich user-band render with `NO_COLOR=1` omits foreground/background colors while keeping its
text. No production terminal behavior changed.

Validation is recorded in [F18 verification](../evidence/F18-verification.txt), and the final
independent review found no remaining findings in [F18 review](../evidence/F18-review.md).
