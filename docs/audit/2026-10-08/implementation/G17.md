# G17: segment and slice analysis

Run reports can now group results independently by the dataset's `group_id` or a nested metadata path. For example:

```text
aibench report RUN_ID --group-by metadata.language --group-by metadata.model.family
aibench report RUN_ID --group-by group_id --format json
/report markdown --group-by metadata.difficulty
```

Each selected field produces a separate marginal summary rather than a cross-product. A segment includes its selected case count, planned/recorded/completed/failed application requests, latency and streaming measurements, warmup measurements, and each scoring pass's metric coverage, decisions, value summary, and evaluator failures. Planned work-item counts supply denominators when available; reports of older runs fall back to recorded observations. Missing and inconsistent case metadata have explicit groups.

Grouping is opt-in, so reports without `--group-by` retain their previous shape. At most eight fields and 100 output groups per field are accepted. When a field has more than 100 categories, the 99 most frequent remain visible and the rest are combined into an `other` row with omitted category and case counts. Every displayed label receives a per-field ordinal, which keeps rows distinct even when content sanitization collapses values. `--no-content` hides category values and uses per-report keyed opaque labels that cannot be guessed from low-entropy metadata; those opaque identifiers intentionally change when the report is regenerated. The public report omits internal grouping keys.

Markdown, HTML, JSON, and the session TUI render grouped summaries. JUnit and SARIF exports reject `--group-by` with a handled error because those formats do not carry aggregate segment sections.

The independent review's first pass found a guessable no-content digest and sanitized-label collisions. Follow-up passes found a label-spoofing edge case and silent acceptance of grouping for JUnit/SARIF. All four were fixed with regression tests; the final review found no actionable findings.
