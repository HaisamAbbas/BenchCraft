# F13 — Use case-macro means in standalone reports

Status: DELIVERED.

Standalone scalar summaries now average the available completed numeric repetitions within
each case, then give each case with a numeric result equal weight. The summary retains the
pooled repetition-weighted mean as a separate diagnostic and records the case and repetition
denominators explicitly. Text reports and the rescore TUI label both estimates so they
cannot be mistaken for each other. Section 12 of the implementation plan now states this
estimand and rule.

Regression coverage reproduces case A values `0, 0`, case B value `1`, and one pending
observation: the primary mean is `0.5`, the repetition-weighted diagnostic is `0.333333`,
and selected/completed/pending counts remain `4/3/1`. A grouped-episode scoring regression
checks that case-level point-estimate weighting remains distinct from repetition weighting.
Validation and independent review are recorded in [verification](../evidence/F13-verification.txt)
and [review](../evidence/F13-review.md).
