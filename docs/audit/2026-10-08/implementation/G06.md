# G06 — Named baselines, tags, and searchable run history

Migration 12 adds run tags and sanitized notes, a current named-baseline catalog, and an
append-only promotion history. `aibench runs list` now searches run identity and annotations
with literal Unicode-aware substring matching, exact status/tag/baseline filters, and stable
newest-first offset pagination. `runs show` and JSON list output include tags, notes, and
current baseline aliases. Metadata reads are chunked below SQLite's traditional bind limit.

Operators can add/remove tags and set/clear bounded notes. Baseline promotion requires a
completed run with complete healthy work, every declared release gate passing, and an
explicit `--approved-by` quality approver. Re-promoting the current run with the same
approver is a no-op; replacements append the previous run ID and approval to history.
`aibench compare ALIAS CURRENT` resolves an alias when no run has that ID, and
`aibench compare @ALIAS CURRENT` forces alias lookup.

See [run history and named baselines](../../../run-history-and-baselines.md) and the
[support summary](../../../support.md#search-and-baseline-management).
