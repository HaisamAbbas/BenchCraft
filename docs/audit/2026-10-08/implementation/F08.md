# F08 — Resolve project settings from the configured project root

Status: DELIVERED. The commit is pushed to `origin/fix/plugin-core-match`.

`chat.project_settings` now resolves configured application, dataset, policy, and plan paths
relative to `ResolvedConfig.root`, which includes `project_root`. Explicit CLI path overrides
remain absolute and take precedence. When no config file exists, paths continue to use the
explicit `--project` root rather than `resolve_config`'s current-directory default. This
fixes nested/monorepo layouts for headless and interactive chat, doctor, and configured-plan
execution.

The regression covers a parent config pointing to a subproject: doctor sees the nested
application, dataset, policy, and plan; headless chat can open the configured project; and
`run` refuses an escaped dataset under the nested policy's `data_roots` before dispatch.
Absolute CLI overrides are covered separately.
