# Phase 21 — Optional dashboard and curated plugin catalog

Status: PARTIAL

## 1. Implemented functionality and changed files

- **21-T1 (local dashboard scope):** `aibench dashboard` serves an optional static UI and
  read-only JSON API from the current workspace. It lists stored run/session summaries,
  shows content-withheld report facts, and compares stored runs only when requested. It
  binds to IPv4 loopback, checks `Host` and `Origin`, rejects write methods, and opens
  query-only SQLite connections per request. Four requests run at once, and report and
  comparison requests reject runs above 5,000 source rows across data they materialize,
  including legacy imported trace observations. It calls the existing report and comparison
  services; it adds no hosting dependency or engine.
- **21-T4 (dashboard scope):** response fields exclude session paths/conversations and run
  environment values. Report facts omit answer/reference text and raw artifacts. The guide
  states that remote access is unsupported because authentication is not implemented.
- Changed paths: `src/aibench/cli/dashboard.py`,
  `src/aibench/services/dashboard.py`, `src/aibench/storage/repositories.py`,
  `src/aibench/cli/main.py`,
  `tests/test_cli_dashboard.py`, `docs/dashboard.md`, `docs/support.md`, `README.md`,
  `docs/engineering/tickets.md`, `docs/engineering/requirements-matrix.md`,
  `docs/engineering/phase-status.md`, and this report.
- **21-T2 and catalog/lifecycle parts of 21-T3 are not implemented.** There is no curated
  plugin catalog, package installation/trust action, revocation system, or catalog audit
  log. Prompt 21 remains partial; no marketplace or deployment is claimed.

## 4. Decisions and specification discrepancies

access is unsupported until an authenticated mode is designed and reviewed. This is recorded
in `docs/dashboard.md`. Reports and comparisons reject more than 5,000 materialized source
rows per run, and active requests are capped at four. The optional catalog and lifecycle work remain separate Prompt 21
scope and are not implied by the G22 dashboard item.
