4. Decisions or specification discrepancies recorded

- **ADR 0015:**
  - source findings are inferred-only, and probes are the only path to an observation;
  - one merged observation per trace, with lowest-span usage;
  - opt-in caches with version-complete keys, and refusals where state or unseen code matters;
  - quotas are checked before task creation, with capped backpressure;
  - blocking file I/O runs off the event loop.
- **Review fixes, all with regression tests:**
  - the execution key covers code, inherited environment and version, and apps whose code can't be seen need a revision;
  - trace merge and upsert;
  - duplicate, conflicting and cyclic spans;
  - junctions and out-of-root entries skipped;
  - context labels for `conftest.py`, `suppress(ImportError)`, `if not TYPE_CHECKING`, TS `import type`, block comments, and token files versus `tokenizer.py`;
  - cancel no longer consults quotas, and the loop always waits when throttled;
  - no head-of-line blocking;
  - Retry-After capped;
  - repetition in the evaluation key;
  - comparisons block on cached executions;
  - no usage event for cache hits;
  - the cache key is released on every completion path;
  - recording an answered call is shielded from cancellation.
- **Recorded, not changed:**
  - **Evaluator backpressure.** Evaluator quotas limit work in flight and the start rate, but don't react to a judge provider's 429. The evaluation contract has no throttling signal, and the adapters retry internally. Adding such a signal is a follow-up.
  - **Quota accounting.** A cache hit still passes through its quota: it takes a token and counts in `started`.
  - **Scorer memory.** `BindingScorer._cache_pending` can keep entries for results that are never finalized. They are bounded by the run's size and live only as long as the scorer.
- **Concurrent work:** another agent edited pass selection in `services/comparison.py` during this prompt. The fresh-measurement checks were added alongside it without touching its changes.
- **Capacity claims:** throughput evidence is from a local mock server only. No million-case or production capacity is claimed (`docs/support.md`, ADR 0015).
