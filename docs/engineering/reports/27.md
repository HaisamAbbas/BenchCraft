# Prompt 27 — Complete conversational evaluation loop

Status: **COMPLETE for the deterministic local loop using configured runners.** The tested
assistant provider is scripted. Live-model quality and human usability have not been evaluated.
The changes close Prompt 24 gaps using the inspector, opportunity, session, policy, execution,
and report services already used by headless commands.

## 1. Implemented functionality and changed files

- **27-T1 — grounded findings and opportunities.** Added a conversation tool backed by the
  session controller's shared application profile and `discover_opportunities` service. The
  conversation can surface objective-specific applicable metrics, evidence gaps, and dataset
  findings while keeping dataset values out of model-facing discovery output. Main paths:
  `src/aibench/conversation/agent.py`, `src/aibench/sessions/controller.py`.
- **27-T2 — clear intent under current policy.** A direct bounded evaluation request can start
  the current validated plan in the same turn; it does not need an extra “run it?” exchange.
  Plan-only requests, questions, negations, mismatched case-count scope, and policy-denied runs
  do not dispatch. The `/run` command now starts the current validated draft and shows its
  preview in the action response. Main paths: `src/aibench/conversation/agent.py`,
  `src/aibench/tui/commands.py`, `src/aibench/tui/app.py`.
- **27-T3 — progress, stored failure evidence, and report provenance.** Active-run progress
  remains queryable as a partial snapshot. Failure/case discussion uses committed results and
  labels causal explanation as a hypothesis. Report facts include sanitized run and metric
  provenance. Main paths: `src/aibench/conversation/agent.py`,
  `src/aibench/services/reports.py`, `src/aibench/sessions/controller.py`.
- **27-T4 — rescore and next experiment.** Added a conversation rescore action that reuses
  stored executions through the policy-checked scoring service, preserves the run ID, and
  reports that it made no application calls. The evidence-based next experiment is a proposal;
  it does not edit or repair the application. Main paths: `src/aibench/conversation/agent.py`,
  `src/aibench/sessions/controller.py`, `src/aibench/services/reports.py`.
- Added the full deterministic conversation fixture and authorization regressions in
  `tests/test_conversation.py`; expanded the terminal journey in
  `tests/test_e2e_cli_journey.py`; added the direct `/run` regression in `tests/test_tui.py`;
  registered it in `scripts/e2e_suite.py`.
- Updated `docs/engineering/tickets.md`, `docs/engineering/phase-status.md`,
  `docs/engineering/requirements-matrix.md`, and
  `docs/engineering/ticket-test-matrix.md`. Clean-install outputs are retained under
  `docs/engineering/evidence/27/`.

No broad refactor, target-application modification, autonomous code repair, new evaluator
vendor dependency, or unconfigured application invocation was added.
