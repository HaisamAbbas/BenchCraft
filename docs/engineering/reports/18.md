### Review follow-up

Closeout review found two validation gaps and added regression coverage:

- Episode validation accepted a plan with no `native.final_state` binding while reporting
  the evaluator as present. It now requires that binding before validating the episodes.
- Source path identity used unconditional case folding, which could reject two distinct
  files whose names differ only by case on a case-sensitive filesystem. It now uses the
  platform's path normalization. The regression test runs on case-sensitive filesystems and
  skips when the filesystem aliases those names.

After these fixes, the affected test files passed: **12 passed, 1 skipped in 17.91s** on
Windows (the case-sensitive-path test skips there). The isolated full-suite run then
reported **885 passed, 33 skipped, 1 failed in 1654.46s**. Its only failure was the existing
100-case crash/recovery timing assertion in `tests/test_mvp_acceptance.py`: the mock service
recorded one in-flight request after the interrupted count (31 versus 30). Rerunning that
test alone passed (**1 passed in 39.64s**). Pytest also emitted two Windows asyncio Proactor
transport cleanup warnings in `test_python_callable_runs_end_to_end_through_the_cli`; that
test passed, and no Prompt 18 runner code was changed.

On the exact staged snapshot, `ruff check src tests examples`, the seven-file format check,
`mypy src` (115 files), schema export, episode CLI validation (2 episodes/4 turns), and
