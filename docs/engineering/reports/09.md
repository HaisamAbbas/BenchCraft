# Phase 09 — Interactive terminal and live controls

Status: COMPLETE

## 1. Implemented functionality and changed files

- **09-T1 — Primary terminal entry.** Bare `aibench` opens chat in a TTY. The explicit
  `chat --project PATH` and `chat --resume SESSION_ID` paths work; bare non-TTY invocation
  prints scriptable-command guidance. The REPL uses `prompt_toolkit` 3.0.53 with multiline
  input (`Esc`, then `Enter`), file history and slash completion. A ConPTY smoke caught and
  fixed a bare-entry invocation bug caused by passing Typer option metadata as values.
  Files: `pyproject.toml`, `requirements-dev.lock.txt`, `src/aibench/cli/main.py`,
  `src/aibench/cli/chat.py`, `src/aibench/tui/app.py`.
- **09-T2 — Streams and evidence.** The OpenAI-compatible provider streams server-sent text
  fragments to the REPL; tool calls render as compact cards. The terminal shows project,
  session, draft revision, run state and coalesced progress from persisted run events.
  Active snapshots are marked provisional; incomplete terminal reports are marked partial;
  the status line shows spend completeness. Input remains available during assistant and
  app work. Files: `src/aibench/planning/openai_provider.py`, `src/aibench/tui/app.py`,
  `src/aibench/tui/render.py`, `src/aibench/services/runs.py`.
- **09-T3 — Slash controls.** Implemented `/help`, `/plan`, `/run`, `/status`, `/pause`,
  `/resume`, `/stop`, `/failures`, `/case`, `/budget`, `/report`, `/sessions`, `/new` and
  `/exit`. They call session/run services directly and remain available without a provider.
  `/report` returns the existing machine-readable summary. Files:
  `src/aibench/tui/commands.py`, `src/aibench/tui/app.py`, `src/aibench/cli/chat.py`.
- **09-T4 — Interruption and exit.** Ctrl+C interrupts the assistant turn only. `/stop`
  explicitly cancels the benchmark. Graceful exit stops dispatch, drains and records
  in-flight work, and leaves remaining work resumable. Reopening a session reports prior
  state without restarting the run. `src/aibench/tui/app.py` uses the existing
  `SessionController.close()` and `RunController.interrupt()` services; no scheduler was
  duplicated.
- Tests and decision record: `tests/chat_server_support.py`,
  `tests/test_openai_provider_stream.py`, `tests/test_tui.py`, `tests/test_cli_chat.py`,
  `tests/test_cli_chat_pty.py`, and `docs/adr/0008-interactive-terminal-and-controls.md`.
- Review follow-ups: the CLI now closes its assistant HTTP client on every exit path, and
  streamed assistant text and tool arguments redact configured secrets even when a secret
  is split across chunks. Regression tests reproduce both issues. Files:
  `src/aibench/cli/chat.py`, `src/aibench/planning/openai_provider.py`,
  `src/aibench/security/secrets.py`, `tests/test_cli_chat.py` and
  `tests/test_openai_provider_stream.py`.
- Ledgers: `docs/engineering/tickets.md`, `docs/engineering/requirements-matrix.md`, and
  `docs/engineering/phase-status.md`.
